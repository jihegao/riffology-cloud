# Riffology Cloud

Riffology Cloud is the next-generation AI-native, multi-user simulation modeling workbench.

This repository will own the product control plane, workspace/session/run domain model,
agent-runtime adapters, and cloud deployment. The existing `riffology-workspace` remains
the legacy production demo, while `riff-pi` remains a local PI WEB integration prototype.

## Status

Repository initialized. Architecture and implementation have not started yet.
