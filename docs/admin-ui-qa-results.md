## 验证范围与方法

使用 Playwright 驱动独立 Chrome 无头浏览器，访问 `http://127.0.0.1:4173`。功能输入通过真实页面按钮、输入框、选择框、键盘和滚动完成；读取 DOM 与本地存储仅用于断言结果。测试浏览器与其他代理的浏览器隔离，完成后已关闭。

覆盖运营总览、官方模型、租户管理、运行管理、用量与结算、操作审计六条管理路由。总计 **62 个断言通过，0 个页面脚本异常**。完整断言记录见 [admin-checks.json](ui-evidence/admin-checks.json)。

验证前按已实现控件建立 A01–A18 清单。正常操作外，额外覆盖空原因、取消操作、重复版本、非法版本号、越界额度、超额补偿、缺失证据、超预留结算、特殊字符搜索及 Escape 关闭弹窗。

- 模型验证按钮载入预设通过结果；发布/撤回改变原型元数据，不上传或部署模型包。
- 金额结算和预留释放是本地示例流程；未验证服务端并发、幂等账本、供应商对账或支付通知。
- 管理端不提供用户项目文件、对话正文或 Preview 读取入口；真实身份授权、隔离和审计不可篡改性需后台验证。
- 管理端价目表为只读示例版本，不包含生产调价审批流程。
- 只在 Chrome 无头环境验证三档视口，未覆盖 Safari、Firefox、真实移动设备与完整辅助技术测试。
