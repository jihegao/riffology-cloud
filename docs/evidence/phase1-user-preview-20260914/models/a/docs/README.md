# Queue FCFS A

这是一个有限、随机的单队列多服务器 FCFS 仿真。顾客按到达顺序进入同一 FIFO 队列；每位顾客在最早可用的相同服务器开始服务。到达间隔和服务时长分别服从参数化指数分布，平台输入的 `seed` 直接用于 `random.Random`，因此同一输入可复现。

`model/run.py` 接受平台的 `--input` 和 `--output`，输出声明的四个有限数值指标，并在输出旁生成 `customers.csv`。CSV 包含顾客、arrival、start、completion、wait，默认40位顾客。依赖为标准库，锁文件为空包集合。Preview 是独立的标准库 HTTPServer，监听 0.0.0.0:8080；/health 仅用于健康检查。

限制：这是有限样本教学模型，不是稳态分析或校准后的现实预测；指数分布、无限等待空间、无放弃/优先级/故障/阻塞等假设可能不适用于具体系统。Preview 中的指标是有界示例，不是平台持久化实验结果；请使用平台参数面板执行并保存实验。可复现记录应包含参数、seed、Python 版本和空依赖锁。
