# G5-A Cloudflare production adapters

`scripts/model/g5-a-cloud-host.mjs` supplies the production-facing seams required by the controlled G5-A serial host. It does not run the benchmark or change Cloudflare by itself.

The private manifest is a mode-0600 JSON file outside tracked source. It names the account, main Worker, frozen Gateway, A window, source/profile hashes, the temporary operator origin, two mode-0600 Wrangler configurations, and a mode-0600 credentials file. Each closed/open entry binds both the normalized configuration SHA-256 used by `compileG5AControl` and the exact Wrangler file SHA-256. Credentials are held on non-enumerable symbol properties, are used only in request headers or the Wrangler child environment, and are absent from returned receipts and JSON serialization.

`createG5ACloudControlPorts` implements the four `runG5ASerialHost` ports. `readConfig` reads the unique 100-percent active deployment and version, verifies the active source digest, then matches its plain-text bindings, required secret names, compatibility date and flags to exactly one frozen normalized config. `deployExact` is disabled unless the adapter was created with `execute: true`; it also re-reads the private config artifact, uploads that approved file with `wrangler versions upload`, discovers the new tagged version with separate before/after version-list reads, deploys that version at 100 percent, and independently re-reads deployment, version, source and config before acknowledging. The caller cannot supply a deploy command or an arbitrary config path.

`readState`, `inspectTask`, `inspectRun`, `inspectFinal`, and `closeAdmission` reuse `createG5OperatorHttpAuthority` and its single `/operate` envelope. `operatorSnapshot()` is the authority for the complete Guard/token/money/tool state. Close first reads its exact digest and then sends the explicit close confirmation and mutation header. The adapter cannot clear unknown work. It does not invent state, admission, or probe HTTP actions.

The admission arithmetic is immutable release input rather than runtime ledger state. The private manifest therefore includes the exact 63-normal-task, 66-maximum-task, three-Group-intent contract. Its receipt SHA-256 binds the A window, source/profile hashes, and both closed/open normalized configuration hashes. `inspectAdmissionContract` only returns this locally frozen value for the same window; it performs no HTTP request and cannot change after manifest loading.

`createG5AReleasePreflight` verifies the active source, profile/window bindings, all five G5-A gates, authenticated no-log/no-cache Gateway, exact container app names, complete instance pagination, zero non-inactive instances and a pristine three-ledger window when control ports are supplied. It returns only identifiers, counts and hashes. `assembleG5ACloudAdapters` creates one consistent authority/control/preflight set. `runG5ACloudSerialHost` binds that set to the same CDP object and driver authority before calling `runG5ASerialHost`; browser cookies remain in Chrome.

The tracked temporary `services/g5-operator/index.ts` supplies snapshot, task/Run/final inspection, and close against the fixed global Guard actor. Fault probes remain unavailable through this adapter and must stay disabled. Version-content verification parses Cloudflare multipart form data, reads `metadata.main_module` or `metadata.body_part`, and hashes the exact selected module bytes; non-multipart content hashes its exact response bytes. This matches the frozen main-module SHA meaning. This commit performed no Cloudflare operation.

Focused validation: `node --test scripts/model/g5-a-cloud-host.test.mjs`. Tests cover private-file permissions and artifact hashes, normalized active-version reads, exact upload/deploy/readback, default mutation refusal, guard/ledger conflicts, source/profile/Gateway/container preflight, capability placement, and secret-free serialization.
