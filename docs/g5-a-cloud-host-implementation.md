# G5-A Cloudflare production adapters

`scripts/model/g5-a-cloud-host.mjs` supplies the production-facing seams required by the controlled G5-A serial host. It does not run the benchmark or change Cloudflare by itself.

The private manifest is a mode-0600 JSON file outside tracked source. It names the account, main Worker, frozen Gateway, A window, source/profile hashes, the temporary operator origin, two mode-0600 Wrangler configurations, and a mode-0600 credentials file. Each closed/open entry binds both the normalized configuration SHA-256 used by `compileG5AControl` and the exact Wrangler file SHA-256. Credentials are held on non-enumerable symbol properties, are used only in request headers or the Wrangler child environment, and are absent from returned receipts and JSON serialization.

`createG5ACloudControlPorts` implements the four `runG5ASerialHost` ports. `readConfig` reads the unique 100-percent active deployment and version, verifies the active source digest, then matches its plain-text bindings, required secret names, compatibility date and flags to exactly one frozen normalized config. `deployExact` is disabled unless the adapter was created with `execute: true`; it also re-reads the private config artifact, uploads that approved file with `wrangler versions upload`, discovers the new tagged version with separate before/after version-list reads, deploys that version at 100 percent, and independently re-reads deployment, version, source and config before acknowledging. The caller cannot supply a deploy command or an arbitrary config path.

`readState`, `inspectProviderFailure`, `inspectTask`, `inspectRun`, `inspectFinal`, and `closeAdmission` reuse `createG5OperatorHttpAuthority` and its single `/operate` envelope. `operatorSnapshot()` is the authority for the complete Guard/token/money/tool state. `inspectProviderFailure` returns only the signed, strictly redacted per-Turn state fields documented in the authority contract. Close first reads its exact digest and then sends the explicit close confirmation and mutation header. The adapter cannot clear unknown work. It does not invent state, admission, or probe HTTP actions.

The admission arithmetic is immutable release input and is also persisted by the Guard authority. The private manifest includes the exact 63-normal-task, 66-maximum-task, three-Group-intent contract and the Guard's SHA-256 receipt over that contract. Source, profile, and both closed/open normalized configuration hashes remain independently bound by the release manifest and B2 assembly checks. `inspectAdmissionContract` reads the durable contract through `/operate`, requires its exact field set and every value including the receipt to match the private freeze, and returns the authoritative value. Missing, extended, or mismatched remote contracts fail closed.

`createG5AReleasePreflight` verifies the active source, profile/window bindings, all five G5-A gates, authenticated no-log/no-cache Gateway, exact container app names, complete instance pagination, zero non-inactive instances and a pristine three-ledger window when control ports are supplied. It returns only identifiers, counts and hashes. `assembleG5ACloudAdapters` remains the low-level control/preflight assembly seam.

The executable production path uses `assembleG5ACloudB2Host`. It loads one private manifest, requires the approved configuration to use `g5-a-b2-controlled`, cross-checks the plan, handoff, configuration, source/profile/window and both gate configuration hashes, then creates the operator authority and `createG5ACdpTransport` itself. Its `readonlyReader` and the same authority instance construct `G5B2ReadonlyProof`; that proof, the same CDP transport, release preflight and authority are injected into the one `G5ASequentialLiveDriver`. `runG5ACloudSerialHost` refuses caller-supplied driver, CDP, authority, proof, control or preflight objects in execute mode and closes the CDP connection after the host finishes. This prevents a legacy-scope driver or proof-free adapter from entering the B2 production path. Browser cookies remain in Chrome.

The tracked temporary `services/g5-operator/index.ts` supplies snapshot, task/Run/final inspection, B2 read-only counter snapshot/attestation, and close against the fixed global Guard actor. Fault probes remain unavailable through this adapter and must stay disabled. Version-content verification parses Cloudflare multipart form data, reads `metadata.main_module` or `metadata.body_part`, and hashes the exact selected module bytes; non-multipart content hashes its exact response bytes. This matches the frozen main-module SHA meaning. This commit performed no Cloudflare operation.

Focused validation: `node --test scripts/model/g5-a-cloud-host.test.mjs`. Tests cover private-file permissions and artifact hashes, normalized active-version reads, exact upload/deploy/readback, default mutation refusal, guard/ledger conflicts, source/profile/Gateway/container preflight, capability placement, secret-free serialization, exact B2 object identity across the production assembly, legacy-scope refusal, approval/manifest binding drift, and injected-adapter refusal.
