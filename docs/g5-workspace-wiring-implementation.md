# G5 Workspace / Turn / simulation wiring

Implementation candidate based on e746cf7; depends on C private grant/authority interfaces (87361b1 initial interface) and Root catalog persistence wiring. No cloud, provider or model execution was performed.

New ordinary Turn submissions under server G5 configuration register and claim their fixed input task, then save an immutable four-field budgetRoute keyed by actual Turn ID before binding the guard task and returning the queued journal mutation. Alarm registration is not execution authorization. Old Turns have no route and retain legacy token namespace interpretation. Route conflicts fail closed.

The real FIFO dispatcher checks the start guard before capacity acquisition and claims native start only after the genuine runtime identity exists. Workspace stores its one-time returned grant, syncs local storage, confirms it, and reads fresh continuation permission. A durable native-accept fence is written before the actual accept RPC; acknowledgement loss becomes observe/reconcile only. The strict runtime identity / capability schema remains unchanged, allowing C to authoritatively route Proxy requests by its exact persisted identity.

Cold and warm terminal handling close the actual three Turn ledgers, choosing G5_TOKEN_BUDGET only from the persisted Turn route, then call closeTrustedTurn so C rereads real settlements. There is no per-model-call Turn closure. Workspace alarms retry unconfirmed terminal closure before admitting later work. Queued cancellations invoke the fixed unstarted-task cancellation without inventing runtime identities; Stop cleanup retains legacy exact native release behavior.

Each simulation childRun freezes its own route/admission before the durable run receipt. Capacity and native stages check the owned confirmed task grant against the current deadline/unknown fences; read-only observation and existing stop/release paths are separate. New G5 Service requests reject before Service admission. WorkspaceTask preserves and strictly validates Root's Project budgetRoute; provisioning coordinator checks start before acquire, dispatch and initialize. Root must leave the Project execution grant claim to Workspace, or explicitly transfer a durable grant with a reviewed interface; the four-field route alone is not a start grant.
