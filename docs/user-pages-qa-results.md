# 用户端页面实际 QA 结果

日期：2026-09-05  
关联清单：[UI 验证清单](ui-qa-inventory.md)  
范围：用户端项目、官方模型库、账单、设置、登录，以及从这些页面进入工作台的上下文。

本文记录实际浏览器操作。原型使用本地示例数据；通过结果只说明界面行为符合设计，不证明身份认证、多租户隔离、真实模型复制、LLM 执行、云端持久化或付费服务已经实现。

## 3. 输入边界与账务一致性

| 编号 | 输入 / 场景 | 实际结果 |
|---|---|---|
| E-01 | 新建名称输入全空格 | 显示“请输入 1–50 个字符的项目名称”，不创建。 |
| E-01 | 新建名称填入 240 个中文字符 | 浏览器依据 `maxlength=50` 截断为 50 字；创建后的卡片稳定换行，页面正常。 |
| E-01 | 名称输入 `QA <script>alert(1)</script>` | 列表按普通文本显示；页面无运行错误，未触发脚本对话框。随后可正常重命名、删除。 |
| E-02 | 预算依次输入 `-1`、`0`、`99999999999999999999` | 全部被拒绝，错误明确范围 ¥0.10–¥1,000；不会写入异常金额。 |
| E-02 | 预算输入非数字 `abc` | number 输入控件不接受字符，提交空值后显示同一范围错误；未默默回退默认值。 |

## 4. 视觉、视口和键盘验证

项目、模型库、账单、设置、登录在以下三个视口的文档宽度均等于视口宽度，`main.scrollWidth` 均等于 `main.clientWidth`，无页面级横向溢出：

| 视口 | 普通页面 main 宽度 | 登录 main 宽度 | 结果 |
|---|---:|---:|---|
| 1440 × 900 | 1218 | 1440 | 通过 |
| 1024 × 768 | 830 | 1024 | 通过 |
| 390 × 844 | 390 | 390 | 通过 |

实际视觉检查包含桌面项目页、全部 6 张模型卡、动态账单、桌面 / 移动登录，以及移动项目、模型、账单、创建弹窗和 Token 明细弹窗。列表按设计在主内容区纵向滚动；宽账单表格在自身容器内横向滚动。

移动 Token 明细弹窗宽 366 px、最大高约 793 px，主体可滚动，关闭按钮固定可达；创建弹窗宽 366 px、高约 615 px，关闭、取消、确认按钮全部位于 390 × 844 视口内。检查了弹窗动画结束后的稳定状态，未以动画中的半透明截图作为结果。

键盘检查：创建弹窗 Escape 关闭后焦点返回触发按钮；Shift+Tab 焦点仍位于弹窗；模型详情关闭返回模型按钮。关键图标按钮有可读名称，搜索字段与切换按钮有明确标签或选中状态。完整屏幕阅读器、自动化可访问性和所有动态颜色组合不在本子任务的验证范围；全局文字对比度由主任务统一复核。

## 5. 已发现并修复

1. **账单导出范围与筛选不一致**：原先选充值只显示 1 条，但 CSV 导出全部 4 条；现筛选和导出共用同一范围，已实际下载复测。
2. **摘要与账单价目不一致**：移除独立的静态月度总量，改用当前已结算账本计算消费、回合数、Token 总量和互斥分类；充值不会混入 AI 消费。
3. **分类计费不可评审**：为三条固定示例添加可核对分类表、单价、版本、金额公式和舍入说明；缺少分类的数据仍明确标为汇总。
4. **移动项目操作过淡**：移除重命名 / 删除按钮组的低透明度，保证触摸页面中常态可见；模型语言标签也使用完整透明度。
5. **长项目名称展示**：标题允许在长连续文本中换行，避免卡片截断标题。

共享布局与工作台问题已通知主任务并在修复后复核：侧栏可用余额减去预留；登录页使用独立布局；非机场项目不会沿用机场仿真内容。

## 7. 仍受限的事项

- 本轮只验证 UI 演示，不验证真实支付、真实认证、平台授权、多租户数据隔离、供应商用量、持久化和后台进程。
- 正式运行资源值仍为清楚标记的示例；没有真实计量服务。Token 固定分类用于评审计费界面和公式，不构成真实消费凭据。
- 预算不足通过可见演示场景验证；真实余额不足、支付待对账、真实网络断线和后台恢复未在此子任务中执行。
- 团队、教学空间、生产级账户变更和真实邮箱验证仅属于后续设计范围。
