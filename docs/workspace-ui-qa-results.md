# 工作台 UI 验证记录

日期：2026-09-05。使用 Playwright 驱动本机 Chrome 无头浏览器，验证本地界面原型。
原始操作结果见 [workspace-checks.json](ui-evidence/workspace-checks.json)。

## 实际操作

| 范围 | 结果 |
|---|---|
| 消息与取消 | 空格消息被拒绝；非空消息完成模拟回合；执行中可取消，反馈明确保留此前示例版本且不产生真实消费。 |
| Session | 新建后为空态；切回原 Session 可见此前消息，项目保持不变；示例回合执行时提示先完成或取消再切换。 |
| Panel | Browser、Files、Changes、Runs 均可切换；关闭后对话扩展，再打开恢复面板；方向键切换页签并保持焦点。 |
| 文件与差异 | 选择 baseline.json 显示对应 JSON；选择 preview.py 显示参数从 2 到 4 的示例差异。 |
| Preview | 保障组从 4 改到 6，等待指标从 12.4 改为 8.4；暂停、重置、刷新、2× 速度、放大与观察摘要均有对应反馈。 |
| 预算 | 负数被拒绝；取消修改后仍要求调整预算；保存 ¥10 后显示“继续回合”，点击才恢复正常。 |
| 故障示例 | 断线、模型超时、观察失败的说明与恢复按钮可用；已有保存版本保持可见。只验证可见场景，不模拟真实网络故障。 |
| 实验 | 开始后进度变化；取消停止确认继续运行；确认停止保留 1 / 20 个样本，下载 CSV 为表头加 1 个样本，含唯一种子与输入版本；另一次完整流程达到 20 / 20。 |
| 日志与附件 | 日志与停止状态、样本计数对应；选择 example.csv 后只附加文件名，并明确不上传文件。取消选择不附加。 |
| 导航和本地状态 | 刷新保留设置与 Session；未知路由回到工作台；浏览器返回可恢复页面；重置后恢复 ¥126.30 可用示例余额。 |
| 弹窗和键盘 | Escape 关闭并返回附件入口；Shift+Tab 保持在弹窗内；手机 Session 弹窗关闭与操作按钮可达。 |
| 手机导航 | 抽屉可打开、关闭，Session / Workspace 可切换，无页面级横向溢出。 |

## 修复与边界

验证中修复了 Session 消息混用、预算取消后误进入继续状态、Diff 项无法切换、CSV 样本计数不一致、飞机动画位置、弹窗初始焦点时序和抽屉遮罩点击区域。
补充固定实验输入版本、页签键盘行为、非机场项目空态与页面刷新后的本地模拟任务中断处理。

未发现页面脚本异常。没有验证真实 Agent、模型执行、容器恢复、文件写入、数据持久化或 Browser 观察能力。
保存失败重试、恢复版本进度与支付未知状态仍为设计项。文件下载入口存在，本次实际下载内容验证集中于实验 CSV；未将文件下载记为已验证。
仅使用 Chrome 无头环境，未验证真实手机、Safari、Firefox 或读屏软件。
