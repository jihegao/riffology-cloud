## Single request, preservation and failure

A separate `native-replacement-publication.lock.json` and each write intent use wx. The old sender and its original locks are never touched. A missing grant stops before a credential loader/client. Following complete local guards and a fresh witness, the script locks the original request, loads the local OAuth once, GET-checks the current Worker/resources/routes/crons/module and release-tag collision, creates one asset session and uploads only server-requested declared unique buckets. It rechecks the full local snapshot plus unchanged grant/source/witness immediately before freezing metadata+completion JWT+module into actual private multipart bytes, and again before exactly one raw Worker PUT. Paths are restricted by the old fixed-account/Worker allowlist. There is no retry, fallback, second PUT, rollback or automatic unlock.

Any error keeps the original request/lock/phase. A lost PUT ACK retains intent and records unknown; the same lock prevents another invocation from replaying. Root must reconcile the original identity by GET only. Even an acknowledged PUT whose post-read fails is not retried or rolled back.

An acknowledged PUT receives a full local readback: all106 bindings,25 exports,6 associations and50 namespace records, original settings/routes/crons/assets-routing and closed policies, with only the expected new release annotation and module. The pending receipt hashes before/after snapshots, original intent, ACK and ACK-time files. It explicitly leaves independent16-app/version/Registry preservation and96 public asset byte readback pending. Offline finalize rechecks those original files/identities and consumes a fresh same-request actual-new-version post witness; it loads no credential, sends no request and never removes the lock. Public byte checks remain separate. Nothing here establishes ordinary-user acceptance or zero historical execution/fees.

The injected test entry accepts only a module-created frozen dummy transport backed by a private WeakMap; returned calls are snapshots. It cannot run a caller-supplied real transport and is unavailable from CLI. Dummy success is only protocol evidence and cannot create the real global publication lock or claim independent live preservation.
